# Providence &middot; Shared Collaboration Hub

Customer-branded GitHub Pages microsite for Providence.

Tells the "Enterprise Application Value Inversion" executive narrative as an
interactive web experience, following the same click-driven tab/panel format
as the Kaiser Permanente + Risant Health and Centene builds, reskinned with
Providence's own brand colors and populated with Providence-specific figures.

Providence is a provider health system (runs Epic as its EHR), not a payer
like Centene, so the Status Quo and Proof-it-works content leans back toward
the original clinical care-journey framing rather than Centene's
payer-specific one.

## Files

| File | Purpose |
|---|---|
| `index.html` | Landing page, published at the root of the repo. Branded with Microsoft + Providence logos. |
| `Providence-App-Value-Inversion.html` | Passcode-gated Decision Canvas. Access code: **`ValueInversion26`** |
| `gate_template.html` | Encryption gate template (used by `encrypt_resource.py`). |
| `encrypt_resource.py` | Helper to encrypt new resource HTML into a passcode-gated page. |
| `build_canvas.py` | Generator script for the raw Decision Canvas HTML, edit this, then re-run, rather than hand-editing the generated file. |
| `raw/decision-canvas.html` | Plaintext source of the Decision Canvas (generated by `build_canvas.py`). Do **NOT** publish, this is the unencrypted original. |
| `assets/` | Providence logo files (color, transparent, plus a programmatically generated white "reverse" variant since no official reverse asset was available) and four generic Microsoft narrative/architecture screenshots reused from the Kaiser Permanente + Risant Health build (no customer-specific branding or numbers in those four), plus `logos-b64.json` (cached base64 encodings used by the build script). |

## Content & format

- **Tabs:** Problem &middot; Status Quo &middot; The Big Question &middot; Opportunity &middot; New Approach &middot; Plan.
- **Problem:** SaaSpocalypse + cost squeeze twin cards, the clickable Then/Now
  Value Inversion stack, the hyperscaler-tax comparison, and the compounding
  cost of a bolted-on data + AI layer.
- **Status Quo:** The Copilot "blind spot" (screenshot, generic), and
  fragmented-context stats with the original clinical care-journey framing
  (pre-diagnosis, diagnosis, treatment, survivorship).
- **The Big Question:** Full-bleed pause-moment screenshot (generic, reused
  from the Kaiser Permanente + Risant Health deck), no other content on the tab.
- **Opportunity:** Providence's own $252.1M AI-BPS TAM (App Development / CRM /
  ERP, clickable vendor categories), the 10-year savings bar chart modeled at
  $1.85/user/month (Power Apps Premium) and $33.44/user/month (Dynamics 365)
  against Providence's 125,000-caregiver-and-staff headcount, and the
  business-outcome stat cards.
- **New Approach:** The clickable Work IQ / Customer IQ / Fabric IQ / Foundry
  IQ / Web IQ five-thing picker, the Microsoft IQ platform architecture
  diagram (screenshot, generic), six provider-specific "proof it works" cards,
  and a compounding-return line chart (native inline SVG, computed from the
  real Providence savings model, not a static screenshot).
- **Plan:** The "scrutiny vs. the question that matters more" reframe, the
  "what it takes to get there" 3-step list, and the closing statement.
- **Branding:** Theme derives automatically from Providence's own brand
  colors, pulled live from providence.org and the local Providence logo file
  on 9/8/2026: primary navy `#00338E` (light mode), bright green `#5CB85C`
  (dark mode pop accent, brightened from the logo's `#39892F`), plus plum
  `#5B3A8E` and teal `#008575` as supporting accents. Supports light/dark
  themes; the hero logo swaps to the white "reverse" variant automatically in
  dark mode.

## Publish to GitHub Pages

> Use your **personal** GitHub account (Pages on the free tier requires a
> personal account and a public repo, not an enterprise account). Check for
> an existing repo of the same name FIRST, Centene already had one in active
> use under a different name pattern.

1. Create a new public repository (e.g. `cx-providence-value-inversion`).
2. Push `index.html`, `Providence-App-Value-Inversion.html`, and `assets/`
   (excluding `raw/` and `assets/logos-b64.json`, see `.gitignore`).
3. Settings &rarr; Pages &rarr; Source = "Deploy from a branch", Folder = `/ (root)`.
4. Live URL: `https://<your-username>.github.io/cx-providence-value-inversion/`

## Editing the canvas later

Do **not** hand-edit `raw/decision-canvas.html` or the encrypted
`Providence-App-Value-Inversion.html` directly, edit `build_canvas.py` (the
CSS, HTML body, JS data arrays, and the savings-model math are clearly
separated in that file), then re-run:

```
python build_canvas.py
python encrypt_resource.py --in raw/decision-canvas.html ^
    --out Providence-App-Value-Inversion.html ^
    --code "ValueInversion26" ^
    --title "Providence Value Inversion Decision Canvas"
```
